# 开工台

面向个人创作者的项目推进工具：记住项目目标、安排下一步、保存参考资料、记录每次工作进度。无需注册，数据保存在浏览器本地，可随时导出备份。

在线使用：https://luckbubby2014.github.io/kaigongtai/

## 页面

- `index.html` — 产品首页
- `app.html` — 工作台（项目 / 下一步 / 任务 / 资料 / 日志 / 收集箱）
- `help.html` / `faq.html` / `about.html` — 帮助、常见问题、关于
- `privacy.html` / `terms.html` / `disclaimer.html` — 隐私政策、服务条款、免责声明

## 技术说明

纯静态网站（HTML + CSS + 原生 JavaScript），无构建步骤、无第三方依赖。数据存储在浏览器 localStorage 中。
