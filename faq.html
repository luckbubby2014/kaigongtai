常见问题

关于账号、数据保存、浏览器兼容和内容使用的常见疑问。

账号与使用

需要注册账号吗？
不需要。打开 开工台 就能创建项目。目前也没有账号、云端同步和付费功能。
我的数据保存在哪里？会被上传吗？
数据保存在你自己浏览器的本地存储（localStorage）中，不会上传到任何服务器。本站也无法看到你填写的内容。详见隐私政策。
换电脑或换浏览器怎么办？
先在旧浏览器点「导出备份」得到一个 JSON 文件，再在新浏览器点「导入」选择这个文件。导入会覆盖当前数据，请提前备份。
清理浏览器数据会丢掉我的记录吗？
会。清除网站数据、使用无痕模式或浏览器自动清理，都可能删除本地保存的内容。请养成定期「导出备份」的习惯。数据丢失的责任约定请见服务条款与免责声明。
支持哪些浏览器？
建议使用较新版本的 Chrome、Edge、Safari 或 Firefox。本站不支持 IE。若遇到无法保存的情况，请检查浏览器是否禁用了本地存储或处于无痕模式。

功能与限制

它和普通待办清单有什么不同？
待办清单记录“有哪些事”，开工台围绕“这个项目要交付什么、下一步做什么、上次做到哪”来组织。核心是让项目持续往前推进，而不是把任务越记越多。
可以多人协作吗？
目前不行。开工台第一版只服务一个人管理自己的项目。是否加入协作功能，要看后续实际需求。
有手机 App 吗？有同步功能吗？
目前没有独立 App，也没有云端同步。本站是网页应用，手机浏览器也可以使用，但数据分别保存在各设备的浏览器里，请分别导出备份。

内容与反馈

在资料里保存的链接、图片版权归谁？
归原权利人所有。资料功能只是记录你自己的收藏与备注。请不要保存、传播侵犯他人权利的内容，也不要将他人作品用于商业用途。详见服务条款中的用户内容条款。
留言与评价怎么用？
打开留言与评价页：给产品打星、选印象标签、写评价或留言。内容保存在你自己的浏览器里，随时可以删除。
站内留言会公开吗？
不会。站内留言和评价默认只保存在你本地浏览器中，本站看不到也不会上传。想公开的话，用「在 GitHub 发表」按钮转为公开评价。
如何在 GitHub 上公开评价？
在留言与评价页写好评分和内容后，点「在 GitHub 公开评价」，会自动带着内容跳到仓库的 Issue 发表页，确认发布即可；也可以直接去 GitHub 评价列表写。
发现问题或有建议，怎么联系？
请见关于本站的联系方式。如涉及侵权投诉，请按免责声明中的知识产权说明提交。
本站和 AI 公司或其产品有关系吗？
没有。本站是独立开发的个人工具，与任何 AI 公司及其产品不存在隶属、授权、赞助或合作关系，也未使用其商标、标识或名称作为本站商标。详见商标与品牌声明。
